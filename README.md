# varpet_rob

Одностраничный лендинг мастерской изделий из натуральной кожи **Varpet Rob** (мастер Роберт, Новокубанск / Армавир).
Чистый HTML / CSS / JS, без сборки и библиотек — просто откройте `index.html`.

## Где что менять
- **Контакты** — `assets/js/main.js`, блок `CONFIG` (телефон, WhatsApp).
- **Работы в слайдере** — массив `WORKS` в `main.js`; фото лежат в `assets/images/works/` (WebP).
- **Подбор изделия** — объект `PREVIEW` в `main.js` (какое фото показывать для изделия и цвета).
- **Этапы работы** — `assets/images/process/`.
- **Отзывы** — скриншот в `assets/images/reviews/`, текст отзывов в `index.html` (секция `#reviews`).
- **Аналитика** — только внутри `loadAnalytics()` в `main.js`, загружается после согласия в cookie-баннере.
- **Политика конфиденциальности** — `index.html`, `<dialog id="privacy">` (152-ФЗ).
