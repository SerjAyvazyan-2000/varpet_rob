# varpet_rob

Varpet Rob — одностраничный лендинг (HTML / CSS / JS, без библиотек)

Открыть: `index.html` (без сборки, без библиотек).

1. Контакты мастера: откройте assets/js/main.js, блок CONFIG в самом верху:
   phone    — номер для показа, напр. '+374 99 123 456'
   whatsapp — только цифры, напр. '37499123456' (заявки и конструктор пойдут в WhatsApp)
   telegram — username без @
   Пока поля пустые, заявки уходят в Instagram Direct (@varpet_rob), а пустые строки контактов скрыты.

2. Фото: иллюстрации в assets/images/*.svg — замените на реальные фото изделий
   (те же имена или поправьте src в index.html). Рекомендуется WebP/JPG ~1200px.

3. Аналитика: подключайте счётчики только внутри функции loadAnalytics() в main.js —
   они загрузятся лишь после согласия в cookie-баннере.

4. Политика конфиденциальности — в index.html (dialog #privacy). Впишите имя/ИП владельца и дату.
